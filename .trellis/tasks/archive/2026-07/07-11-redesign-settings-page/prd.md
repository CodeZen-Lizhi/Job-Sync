# 彻底重构全站产品 UI

## Goal

保留 JobPilot 全部业务功能、数据契约和操作入口，废弃现有页面的视觉结构，按 shadcn 产品工作台语言重新设计应用外壳、职位库、采集、采集配置、简历库与设置页。

## Background

- 用户明确否定现有视觉方案，尤其是职位库平铺筛选器、重复卡片和缺少产品层级的问题。
- 本次不是局部美化：旧布局不作为约束，允许重排页面信息架构和展示结构。
- 项目为 Vue 3 + Tailwind CSS 3 + Tauri，现有设置状态、IPC、保存逻辑、诊断逻辑和 Hash Router 页面行为必须保持不变。
- 工作区已有 `src/pages/CrawlConfig.vue` 的紧凑定时采集改动，现纳入本次全站重构并继续保留。

## Requirements

### R1. 产品级应用骨架

- 重新设计桌面侧栏、移动导航、页面 header、内容容器与通用状态层级。
- 使用 shadcn 的 neutral token、细边框、克制阴影和高密度工具布局，但不机械堆叠 Card。
- 所有页面在桌面和移动端共享一致的导航、标题、工具栏、表单和空态语言。

### R2. 职位库彻底重构

- 职位库重建为摘要、视图分区、主搜索、按需高级筛选、结果工具栏和可扫描职位行。
- 默认不同时铺开全部筛选控件；现有时间、处理状态、岗位状态、AI、平台、采集方式和自定义日期功能全部保留。
- 职位行突出岗位、公司、地点、薪资、匹配分和当前状态，详细操作按需展开。

### R3. 全页面重构

- 采集页重构为运行控制台；采集配置使用渐进展开；简历库使用稳定 master-detail；设置页使用类别导航与单一内容区。
- 删除重复标题卡、说明墙、卡片套卡片和同权重操作。
- 加载、空态、错误、禁用、弹层和菜单保持完整且统一。

### R4. 功能与行为完整性

- 不删除或弱化现有采集、筛选、职位操作、简历编辑、平台登录、模型设置、通知、诊断和导出功能。
- 可以新增纯 UI 展开/切换状态，但不改变 IPC、路由、保存 payload、数据库或 worker 契约。
- 非 Tauri 浏览器预览继续显示不可用提示并可完成视觉验证。

### R5. 兼容性

- 不修改设置字段、IPC 命令、持久化格式、业务逻辑、平台登录流程或诊断摘要内容。
- 不新增 UI 框架、图标库或网络字体。
- 保持键盘 focus、disabled、aria 状态和 reduced-motion 行为。

- [x] 职位结果行和详情区具备清晰的信息优先级，所有原操作保持可达。

- [x] 平台、模型、Telegram、诊断、职位操作、简历和采集功能均未削减。
- [x] 1280×800 与 390×844 下无页面级横向溢出、遮挡或不可达关键操作。
