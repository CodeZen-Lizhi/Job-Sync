# 设置页紧凑偏好面板

## Goal

将设置页从纵向铺开的长文档重构为紧凑、清晰、符合桌面系统习惯的偏好设置界面，让用户快速定位类别、修改配置并保存。

## Background

- 原页面同时展开平台、浏览器、网络、模型、通知和诊断，篇幅过长且说明文字密集。
- 项目为 Vue 3 + Tailwind CSS 3 + Tauri，设置状态、IPC、持久化和诊断契约必须保持不变。
- 同一工作区存在另一轮全站 UI 改动；本任务只拥有 `Settings.vue` 和本次新增的设置页规范，不提交其他脏文件。

## Requirements

- 桌面端使用类别导航与单一内容区，一次只展示一个设置类别。
- 类别为平台与登录、模型服务、网络与浏览器、通知、系统诊断。
- 标题不超过 20px，正文与表单以 12–14px 为主，减少面板内边距和默认展开内容。
- 平台列表保留全部状态和操作，技术说明按需展开。
- 模型高级提示默认收起，保留三个原字段。
- 页面只保留一个保存入口，并继续展示成功、失败和登录反馈。
- 不修改字段、IPC、路由、保存 payload、登录流程或诊断摘要安全边界。

## Acceptance Criteria

- [x] 默认只展示一个设置类别，不再一次性铺开全部配置。
- [x] 平台、模型、代理、浏览器、Telegram 与诊断功能均保持可达。
- [x] 高级 AI 提示默认收起，可展开编辑全部三个字段。
- [x] 页面只有一个保存入口，标题计算字号为 20px。
- [x] 1280×800 与 390×844 无页面级横向溢出，类别切换不改变 `/#/settings`。
- [x] `npm run build`、设置页 5 条定向契约测试和 `git diff --check` 通过。
- [x] 浏览器控制台无 error 或 warning。

## Verification Results

- 桌面 1280×800：页面宽度等于视口宽度，分类双栏正常。
- 移动 390×844：页面宽度 390px；类别导航仅在自身内部滚动；模型页只有一个保存按钮。
- 高级提示默认关闭，展开后 3 个 textarea 可见。
- 本任务实现完成时全量契约测试曾为 61/61；最终复核期间并行全站任务修改 Jobs 相关文件，使共享工作区全量结果变为 55/61。失败项均不涉及 `Settings.vue`，设置页定向测试为 5/5。

## Out of Scope

- 修改其他页面、全局应用外壳、后端、Rust、worker 或数据库。
- 新增暗色模式、主题切换或新的业务设置项。
