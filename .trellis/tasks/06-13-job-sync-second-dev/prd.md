# Job-Sync 二开需求实现

## Goal

按 `docs/job-sync-remote-tech-jobs-requirements.md` 推进二开：把现有 Boss 采集、SQLite 职位库、AI 分析、简历优化和 PDF 导出能力，强化为面向国内技术岗的本地优先求职研究系统。

核心闭环：

```text
找到真正适合的岗位 -> AI 分析匹配度 -> 人工确认 -> 精准投递
```

## Requirements

- Phase 0：Mac Tauri 开发、sidecar、Chrome 路径和打包适配应保持可运行。
- Phase 1：Boss 岗位进入统一职位来源模型；其他平台只预留 adapter 和来源字段。
- Phase 2：默认筛选画像支持硬限制、排除条件和偏好加权，覆盖关键词、方向、技术栈、工作方式、城市、来源平台、沟通状态、薪资、经验、学历和公司条件。
- Phase 3：硬限制之后计算 Resume Match Score、Preference Score、Company Score 和 Final Score，并按权重展示 Top 20 人工审核队列。
- Phase 4/5/7：黑名单、沟通状态、公司/职位人工判断和审核状态参与推荐过滤；用户可以收藏、忽略、准备投递、标记已投递、标记不合适和拉黑。
- Phase 6：Company Score 至少能用本地启发式识别外包、驻场、培训、电话销售和低信息风险，并可按公司复用。
- Phase 8：人工确认后生成可编辑、可复制的定制打招呼文案；不得自动发送。
- Phase 9：每日岗位情报展示新增、高匹配、满足关键限制、推荐投递、准备投递和已投递统计；通知只作为入口，不触发投递。
- Phase 10：模型供应商支持 OpenAI Compatible、DeepSeek 和 Ollama，API Key 不明文回显，结构化输出失败要有明确错误和重试入口。
- 简历工作区和 PDF 导出要能和筛选后的岗位联动，投递材料包只能用于人工复制和确认。

## Acceptance Criteria

- [x] Mac Chrome 默认路径、开发态 node sidecar 和当前平台 release staging 已适配。
- [x] Boss 来源写入统一职位字段、来源 URL、去重 key、原始 payload 和 source adapter 注册表。
- [x] 默认筛选画像支持 Boss-only 硬限制、排除、偏好和重算。
- [x] Top 20 按可解释综合评分排序，并展示评分、硬限制/筛选通过证据、公司风险和沟通状态；可复制 Top 20 人工审核摘要用于本地研究和人工确认。
- [x] 黑名单、已拒绝、已读未回、手动不合适、已忽略和已投递不会进入默认 Top 20。
- [x] 用户可以在职位库执行人工审核、沟通状态、沟通回溯摘要复制、公司判断、职位/公司/关键词黑名单和恢复候选操作。
- [x] 准备投递前确认、准备投递队列、整队投递准备清单、携带筛选画像证据的投递材料包、打招呼文案、原平台来源页回跳和简历工作区联动保持手动复制/手动确认边界，并提示简历匹配、最终简历/PDF 和文案缺口。
- [x] 每日岗位情报可以从本地数据生成，推荐候选带来源追踪、推荐理由和手动复制摘要，并支持本机通知入口。
- [x] 模型供应商、Temperature、Prompt Extra、API Key 脱敏和 AI 失败重试入口已接入。
- [x] 多筛选画像管理和策略切换已实现：用户可以保存多个画像、切换当前画像、设为默认策略，并用当前默认画像重算候选队列。
- [x] Boss 之外的平台手动导入 adapter 已实现：猎聘、智联、脉脉、V2EX 和 LinuxDo 可导入单条岗位 JSON，写入统一职位来源模型并参与本地筛选/排序；导入面板提供平台示例模板和导入后来源核对摘要复制，筛选画像提供 Boss-only、手动导入来源和全来源快捷切换；尚未实现各平台自动爬虫。
- [x] 本地启发式 Company Score 批量缓存重建已实现，可从 Top 20 审核队列手动触发并刷新候选排序，风险标签会以中文标签展示用于人工审核。
- [x] AI Company Score 批处理已实现：Top 20 审核队列可手动触发模型生成公司评分，结果写入 `company_score` 缓存并刷新候选排序。
- [x] 邮件通知草稿入口已实现：每日岗位情报可打开本机邮件客户端草稿，内容只包含摘要和入口，不自动投递。
- [x] 企业微信机器人 webhook 手动通知已实现：每日岗位情报可手动发送到企业微信，Webhook 本地保存且不在 UI 回显，不自动投递。
- [x] 结构化输出 schema 补充配置已实现：设置页可配置 Schema Extra，Rust 写入 worker 环境，AI prompt 会追加补充约束，worker 校验保留内置必填字段并允许额外字段透传。
