# 父级完成审计与外部验收清单

## Goal

为 `docs/job-sync-remote-tech-jobs-requirements.md` 做父级完成审计，形成一份可复查的验收文档：明确当前仓库已经由代码、测试、构建和烟测证明的范围，以及仍需用户本机凭据/服务参与的外部依赖实测项。

## Requirements

- 审计必须覆盖需求文档 Phase 0-10 和 19 条总体验收标准。
- 审计必须引用当前仓库内的证据来源，例如覆盖审计、代码/测试文件、已记录的构建或烟测结果。
- 审计必须区分“仓库内已闭环”和“需要用户本机外部状态验证”，不能把真实 Boss 登录、真实模型服务或企业微信外网发送伪装成已完成。
- 提供可执行的外部依赖手动验收清单，说明前置条件、操作路径、期望结果和可复制证据。
- 父任务 PRD 和覆盖审计应能指向该最终验收文档。

## Acceptance Criteria

- [x] 新增最终验收审计文档，覆盖 Phase 0-10 和 19 条总体验收标准。
- [x] 文档列出剩余外部依赖实测项，并给出用户本机可执行的手动验收步骤。
- [x] 父任务 PRD 或覆盖审计链接到最终验收审计文档。
- [x] 文档不包含密钥、Webhook、Cookie、LocalStorage 或其他敏感值示例。
- [x] 运行必要的文档/契约验证并记录结果。

## Notes

- 这是父任务收口文档任务，不新增自动投递、自动开聊、平台风控绕过或真实外部服务调用。
- 全局目标不因本任务自动完成；只有用户本机外部依赖证据也齐全后，才能宣称完整实机闭环。
