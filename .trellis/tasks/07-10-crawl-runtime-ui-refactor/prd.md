# 重构采集运行页 UI

## Goal

把采集运行页重构为紧凑、清晰的桌面运营控制台，让用户在首屏完成启动/停止操作并看清批次统计和运行日志，同时保持现有采集业务行为不变。

## User Value

- 来源、状态、运行参数和操作形成连续工作流，不再散落在大面积空白区域两端。
- 统计由四张重复卡片收敛为一个可快速扫描的指标区域。
- 日志成为主要反馈区，在常见桌面视口首屏即可看到有效内容。

## Confirmed Facts

- 用户截图中控制区、统计区和日志区被拆成多个大块；延迟输入、状态和按钮距离过远，视觉重心失衡。
- 浏览器实测 `1280x720`：`src/pages/Crawl.vue:62-88` 的控制面板高约 `248px`，数值输入宽约 `460px`；日志面板从 `y=558` 开始且固定高 `320px`，首屏无法完整看到运行反馈。
- `src/components/crawl/CrawlActionBar.vue:14-24` 与 `src/components/crawl/CrawlRuntimePanel.vue:73-84` 重复展示运行状态。
- `src/components/crawl/CrawlRuntimePanel.vue:49-70` 使用四张独立统计卡，固定占用约 `110px` 高度，并以多种高饱和颜色强调同层级数字。
- `src/styles/tailwind.css:253-276` 将日志面板固定为 `320px`；日志行已有时间、级别和消息三列数据，不需要改变日志契约即可重排。
- `src/lib/useCrawlPage.ts:381-388` 已提供 `selectedCollectionSourceLabel`，运行页尚未展示该来源摘要。
- `390x844` 实测没有页面级横向溢出，但导航、页头、提示和控制区几乎占满首屏，运行反馈需要继续下滚。
- 当前独立任务 `07-10-job-display-approved-only` 正在修改批次统计及同一组 Vue 组件；本任务必须在该任务完成或工作树稳定后开始，复用其最终 summary 契约。

## Requirements

### R1. Compact Run Control

- 将运行标题、来源摘要、唯一运行状态、延迟输入和开始/停止操作组织在一个紧凑控制区域内。
- 桌面端限制延迟数值输入的语义宽度，不允许继续拉伸到半行或更宽。
- 展示 `selectedCollectionSourceLabel`，并保留前往采集配置页的入口。
- 运行状态只保留一个权威展示位置；开始/停止按钮现有 enable/disable 条件和事件契约不变。

### R2. Grouped Batch Metrics

- 将“总搜到 / 未新增 / 新入库 / 通过”收敛为一个分段指标条，桌面四列、窄屏 `2x2`。
- 指标数值使用统一的主文本层级，语义色只用于小型标识或状态提示，避免彩虹式卡片。
- 指标标签、辅助文案和数值继续来自统计修复任务提供的结构化批次 summary，不解析日志文本。

### R3. Runtime Log Workspace

- 日志区占用页面剩余可用高度并在内部滚动；桌面首屏必须出现日志标题和有效正文区域。
- 日志头部仅保留标题、条数和清空操作，不重复运行状态。
- 保留时间、严重级别和消息内容；信息、警告、错误应有克制且可区分的视觉提示。
- 无日志时显示明确空状态，不留下无含义的大块空白。

### R4. Responsive And Accessible Behavior

- `1280x720` 和 `390x844` 均不得出现页面级横向滚动、文字裁切或控件重叠。
- 窄屏允许控制项和日志头部按设计换行，按钮和指标尺寸必须稳定。
- 保留可见 focus、disabled 语义和现有实际点击区域；运行状态动效遵守 reduced-motion。
- 使用现有 Tailwind token、`ui-*` 类和 Lucide 图标，不新增依赖。

### R5. Scope And Compatibility

- 仅调整采集运行页、相关 crawl 组件和 crawl 专用样式。
- 保持采集、去重、AI 判断、通知、路由、IPC 参数及持久化行为不变。
- 不覆盖统计修复任务或工作树中的其他用户改动。

## Acceptance Criteria

- [ ] `1280x720` 浏览器模式下无横向滚动，日志标题及至少一部分正文位于首屏内。
- [ ] 桌面端延迟输入不再占据半行；来源、状态、参数和操作形成连续控制区。
- [ ] 运行状态只展示一次，四项指标位于一个分段区域内，桌面四列、窄屏 `2x2`。
- [ ] `390x844` 下无横向溢出、裁切或重叠；开始、停止和清空日志仍可识别和操作。
- [ ] 空日志、有日志、警告、错误、空闲、运行中和浏览器禁用态均有明确呈现。
- [ ] 统计修复后的 summary 字段、数值口径和刷新行为未被 UI 重构改变。
- [ ] `npm run test:review-workflow` 与 `npm run build` 通过。
- [ ] 浏览器完成桌面与窄屏烟测；Tauri 最小烟测确认真实开始/停止状态和日志渲染正常。
- [ ] 代码修改后使用 `trellis-check` 和 `code-review-and-quality` 审查，未发现当前范围内明显问题或已完成修复复验。
