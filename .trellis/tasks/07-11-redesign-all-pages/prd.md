# 重构所有页面前端布局

## Goal

在不改变现有业务能力和数据契约的前提下，重构 JobPilot 桌面端全部可访问页面的布局与视觉体系，使产品形成统一、清晰、有辨识度且适合高频操作的求职工作台体验。

## Background

- 用户明确认为当前所有页面整体视觉效果差，希望进行全局布局重构，而不是继续修补单个页面。
- 当前前端为 Vue 3、Vue Router、Tailwind CSS 与 Tauri 桌面应用，共有 5 个可访问路由页面：采集、采集配置、职位库、简历库、设置；`/export` 已重定向到职位库。
- 应用外壳采用固定左侧栏、浅灰背景、白色面板和蓝色强调色；页面大量复用 `ui-panel`、`ui-card`、`ui-btn-*` 等全局样式类。
- 2026-07-05 已做过一轮全局 UI 优化，2026-07-10 又单独重构采集运行页，但现有方向仍未满足用户审美要求，因此本次必须重新确立视觉方向，而不是延续原有“白色卡片堆叠”方案。
- 真实页面检查显示当前整体偏“通用后台模板”：浅灰底、白卡、细边框和小字号在所有页面高频重复，视觉层级主要依赖框线而非排版与空间关系。
- 桌面端侧栏占用固定宽度，但品牌区和导航区信息密度低；内容区标题、提示条、工具栏与面板之间缺少鲜明的主次节奏。
- 职位库窄屏没有横向溢出，但顶部导航依赖水平滚动且末项被截断；页面首屏同时出现品牌头、导航、双语 kicker、标题、说明、工具按钮、警告和筛选面板，纵向层级较碎。
- 设置页将多类平台能力与表单连续铺成长页面，缺少分区导航或更明确的配置层次；空数据页面则出现大面积无意义留白。
- 上一轮全局 UI 任务采用“紧凑浅色后台、统一小圆角面板”的方向，本次不再重复该方案，而以更强的应用骨架、任务化布局和排版层级建立产品辨识度。

## Requirements

### R1. 全局视觉系统

- 采用用户确认的“精致专业工作台”方向：深墨色导航、暖白内容区，以靛蓝和翡翠作为功能强调色，通过排版、留白和局部底色建立层级。
- 建立一套明确且统一的颜色、字体、间距、圆角、边框、阴影、层级和交互状态规范。
- 降低同质化白色卡片、重复边框和碎片化小标题造成的模板感。
- 导航、页面标题、工具栏、表单、列表、状态、空态、弹窗与操作按钮必须属于同一视觉语言。
- 保持中文信息在桌面端常见视口下清晰可读，不以装饰牺牲操作效率。

### R2. 应用外壳与导航

- 重构桌面侧栏、移动端导航和主内容区的空间关系，使产品品牌、页面定位和当前导航状态更清楚。
- 保留现有路由与导航信息架构，不新增或删除业务入口。
- 主内容宽度应根据页面任务密度合理变化，不出现无意义的大面积空白或过度拥挤。

### R3. 全页面布局重构

- 覆盖 `/crawl`、`/crawl-config`、`/jobs`、`/resume-library`、`/settings` 五个可访问页面及其直接使用的展示组件。
- 每个页面应根据任务类型采用合适布局，而不是机械套用同一种卡片模板。
- 保留现有业务流程、数据字段、加载/错误/空状态、按钮权限与操作语义。
- 已重构的采集运行页可以再次调整，但不得破坏结构化批次统计、唯一状态来源和弹性日志区等已确认约束。

### R4. 响应式与可访问性

- 桌面窗口和窄屏下不得出现关键内容横向溢出、控件遮挡、不可操作或文本异常截断。
- 保持键盘焦点、禁用态、错误态、加载态和语义化区域可辨识。
- 动效用于建立层级和反馈，需克制且不得影响操作性能。

### R5. 技术与范围约束

- 优先复用 Vue、Tailwind CSS、Lucide 图标和现有组件能力，不因纯视觉重构新增重量级 UI 依赖。
- 尽量将共享视觉规则收敛到全局样式与通用组件，避免五个页面形成五套重复实现。
- 不修改采集、职位、简历、设置等业务数据契约，不修改 Rust、数据库 Schema 或 worker 行为。

## Acceptance Criteria

- [x] 五个可访问页面及应用外壳均完成布局和视觉重构，并形成一致的产品识别。
- [x] 页面不再主要依赖同质白色卡片与重复边框表达层级；不同任务区有明确的信息主次。
- [x] 采集、配置、职位浏览、简历编辑和设置表单的核心操作路径保持可用，业务语义无回归。
- [x] 桌面常用视口与窄屏视口均无关键横向溢出、重叠、遮挡或不可点击控件。
- [x] 加载、空态、错误、成功、禁用和弹窗状态在新视觉系统下保持清晰。
- [x] `npm run test:review-workflow` 与 `npm run build` 通过。
- [x] 使用真实页面完成桌面和窄屏视觉烟测，控制台无由本次改动引入的错误。
- [x] 改动通过 Trellis 检查和通用代码质量审查。

## Out of Scope

- 新增业务功能、改变导航信息架构或重写业务状态管理。
- 修改后端、数据库、采集 worker、AI 规则或接口协议。
- 为视觉效果引入大型组件库、复杂三维效果或持续高耗能动画。
